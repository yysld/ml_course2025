# 7. 多分类扩展

## 7.1 SVM的多分类策略

到目前为止，我们讨论的SVM都是针对二分类问题的。无论是硬间隔、软间隔还是核SVM，其核心思想都是寻找一个超平面将两类样本分开。然而，实际应用中我们经常面对多分类问题：手写数字识别需要区分0-9共10个类别，图像分类可能涉及成百上千个类别。那么，如何将SVM推广到多分类场景？

一个自然的想法是：能否直接修改SVM的优化目标，使其一次性处理多个类别？理论上确实存在这样的多类SVM公式，但它会导致优化问题的规模急剧膨胀，约束条件数量从 $n$ 增长到 $n \times (k-1)$（$k$ 为类别数），实际求解非常困难。因此，实践中更常用的策略是将多分类问题分解为多个二分类问题，用已有的二分类SVM分别求解，再将结果综合起来。这种分解策略主要有两种：一对一（One-vs-One, OvO）和一对其余（One-vs-Rest, OvR）。

### 7.1.1 一对一（One-vs-One）

一对一策略的思路非常直接：既然SVM擅长处理两类问题，那就让它专注于两类之间的区分。对于一个 $k$ 类分类问题，我们枚举所有可能的类别对 $(i, j)$，为每一对训练一个专门的二分类器。

具体来说，假设我们有 $k$ 个类别，一对一策略的操作如下：对于每一对类别 $(i, j)$（其中 $i < j$），我们从训练集中取出所有属于类别 $i$ 和类别 $j$ 的样本，忽略其他类别，然后在这个子集上训练一个标准的二分类SVM。这个分类器只负责区分类别 $i$ 和类别 $j$，对其他类别一无所知。

这样的类别对有多少个？从 $k$ 个类别中选取两个的组合数为：

$$
\binom{k}{2} = \frac{k(k-1)}{2}
$$

因此，对于一个10类问题（如手写数字识别），我们需要训练 $\frac{10 \times 9}{2} = 45$ 个分类器；对于100类问题，则需要4950个分类器。

当一个新样本 $\mathbf{x}$ 到来时，如何利用这些分类器进行预测？这里采用投票机制：让每个分类器对 $\mathbf{x}$ 进行预测，每个分类器会投票给它认为的类别。遍历所有 $\frac{k(k-1)}{2}$ 个分类器后，统计每个类别获得的票数，票数最多的类别即为最终预测结果。

📐 **一对一投票决策**

设 $f_{ij}(\mathbf{x})$ 为区分类别 $i$ 和类别 $j$ 的分类器的决策函数，投票计数为：

$$
\text{vote}_c = \sum_{i < c} \mathbb{1}[f_{ic}(\mathbf{x}) < 0] + \sum_{j > c} \mathbb{1}[f_{cj}(\mathbf{x}) > 0]
$$

最终预测类别为：$\hat{y} = \arg\max_c \text{vote}_c$

这个公式看起来复杂，其实逻辑很简单：对于类别 $c$，我们检查所有涉及它的分类器（共 $k-1$ 个），如果某个分类器判定样本属于类别 $c$，就给 $c$ 投一票。最后选择得票最多的类别。

💡 **提示**：当出现票数相同的情况时，不同的实现可能采用不同的策略。sklearn的SVC采用按类别编号顺序选取的方式，但这种平局情况在实践中较为少见。

一对一策略有几个显著的优点。首先，每个分类器只需要处理两个类别的样本，训练集规模较小，单个分类器的训练速度快。其次，每个二分类问题都相对平衡——类别 $i$ 的样本与类别 $j$ 的样本通常不会有极端的数量差异。此外，这种方式让每个分类器可以针对特定的两类边界进行优化，决策边界可能更加精细。

然而，一对一策略也有明显的缺点。分类器数量随类别数二次增长，当类别很多时，不仅训练时间长，预测时也需要运行所有分类器进行投票。另外，投票机制可能产生难以解释的结果：某些分类器可能对给定样本完全不相关（比如区分"猫"和"狗"的分类器对一张"鸟"的图片的投票），但它们的票数权重与其他分类器相同。

### 7.1.2 一对其余（One-vs-Rest）

一对其余策略采用另一种分解思路：不是让每对类别互相比较，而是让每个类别与所有其他类别竞争。对于 $k$ 个类别，我们训练 $k$ 个分类器，第 $c$ 个分类器的任务是区分"类别 $c$"与"非类别 $c$"。

具体操作如下：对于类别 $c$，我们将所有属于类别 $c$ 的样本标记为正类（+1），将所有其他类别的样本合并在一起标记为负类（-1），然后训练一个二分类SVM。这个分类器学习的是"什么样的样本属于类别 $c$"这个问题。

这样我们只需要 $k$ 个分类器，相比一对一策略的 $\frac{k(k-1)}{2}$ 个，在类别数较多时有明显优势。对于10类问题需要10个分类器，对于100类问题需要100个分类器，增长是线性的。

预测时，我们让所有 $k$ 个分类器对新样本 $\mathbf{x}$ 计算决策值，选择决策值最大的类别作为预测结果。这里用的是决策函数的值（到超平面的带符号距离），而不是简单的类别预测。为什么？因为每个分类器输出的决策值 $f_c(\mathbf{x}) = \mathbf{w}_c^\top \mathbf{x} + b_c$ 可以看作样本属于类别 $c$ 的"置信度"——值越大，说明样本越偏向类别 $c$ 的那一侧。

📐 **一对其余决策规则**

设 $f_c(\mathbf{x})$ 为第 $c$ 个分类器（区分类别 $c$ 与其余类别）的决策函数，预测类别为：

$$
\hat{y} = \arg\max_{c \in \{1, 2, \ldots, k\}} f_c(\mathbf{x})
$$

这个决策规则有一个隐含的假设：不同分类器的决策值是可比较的。然而实际上，每个分类器是独立训练的，它们的决策值尺度可能不同。一个分类器可能倾向于输出较大的绝对值，另一个可能较保守。这种不一致性可能导致预测偏差。实践中，有时会对决策值进行校准（如Platt缩放转换为概率），但sklearn默认的SVC实现并不做这种校准。

一对其余策略还面临一个结构性问题：类别不平衡。假设我们有5个类别，每类100个样本，总共500个样本。当训练第 $c$ 个分类器时，正类有100个样本，负类有400个样本，正负比例为1:4。如果某个类别本身样本就很少，这种不平衡会更加严重。类别不平衡可能导致分类器过度偏向预测负类，需要通过调整类别权重（`class_weight`参数）来缓解。

一对其余策略的优点在于分类器数量少，训练和预测都更高效；每个分类器利用了全部训练数据，可能学到更具全局性的特征。缺点则包括刚才提到的类别不平衡问题，以及不同分类器决策值的不可比性。此外，每个分类器需要处理全部样本，单个分类器的训练成本比一对一策略中的分类器更高。

两种策略各有适用场景。一般而言，当类别数较少（如 $k < 10$）时，一对一策略的分类器数量可以接受，且每个分类器训练数据平衡，效果通常较好；当类别数较多时，一对其余策略的效率优势更明显。sklearn的SVC默认采用一对一策略，而LinearSVC默认采用一对其余策略——后者是因为线性SVM可以高效处理大规模数据，一对其余的效率优势更为突出。

### 7.1.3 sklearn中的多分类实现

在sklearn中，多分类SVM的使用对用户来说几乎是透明的：只需像往常一样调用`fit`和`predict`，底层会自动处理多分类逻辑。但了解背后的实现细节有助于理解模型行为和调优。

`SVC`类默认采用一对一策略。这是因为其底层调用的libsvm库原生支持一对一多分类。当训练数据包含多个类别时，`SVC`会自动训练 $\frac{k(k-1)}{2}$ 个分类器，预测时采用投票机制。

`LinearSVC`类默认采用一对其余策略。它基于liblinear库实现，这个库针对线性模型做了大量优化，一对其余策略与其高效的坐标下降求解器配合良好。

两个类都提供了`decision_function`方法来获取决策值，但输出的形状和含义因策略不同而异。这里涉及一个重要参数：`decision_function_shape`。

对于`SVC`，`decision_function_shape`参数控制`decision_function`方法的输出格式。当设为`'ovr'`（默认值）时，即使底层使用一对一训练，`decision_function`也会返回一个形状为 $(n, k)$ 的数组，每个样本对应 $k$ 个值，可以理解为对 $k$ 个类别的"得分"。这是通过对一对一投票结果进行变换得到的，方便用户理解和使用。当设为`'ovo'`时，返回原始的一对一决策值，形状为 $(n, \frac{k(k-1)}{2})$。

⚠️ **注意**：`decision_function_shape`参数只影响`decision_function`的输出格式，不影响模型的训练方式。`SVC`始终使用一对一策略训练，这个参数只是决定如何呈现结果。

对于`LinearSVC`，由于本身就是一对其余训练，`decision_function`直接返回 $(n, k)$ 形状的数组，每列对应一个类别的决策值。

下面是一个简单的代码示例，展示如何使用多分类SVM：

```python
from sklearn.svm import SVC, LinearSVC
from sklearn.datasets import load_iris

X, y = load_iris(return_X_y=True)  # 3类问题
svc = SVC(kernel='rbf').fit(X, y)  # 一对一，3个分类器
lsvc = LinearSVC().fit(X, y)       # 一对其余，3个分类器
```

在选择使用哪种实现时，可以参考以下经验：如果使用非线性核且类别数适中，`SVC`是默认选择；如果数据规模大、特征维度高、使用线性核，`LinearSVC`效率更高；如果类别数非常多（如数百个），可能需要考虑其他专门的多分类方法或层次分类策略。

总结一下，SVM通过将多分类分解为多个二分类来处理多类问题，一对一和一对其余是两种主流策略。一对一策略训练更多但更小的分类器，通过投票决策；一对其余策略训练更少但更大的分类器，通过比较决策值决策。两种策略各有优劣，sklearn提供了灵活的实现供用户选择。
